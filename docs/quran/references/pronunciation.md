# Quran Pronunciation Reference

## Purpose

This document contains references for future pronunciation,
phoneme, Tajweed, and Makharij features.

## Current MVP

MVP does NOT evaluate Tajweed or Makharij.

MVP only determines whether the user's recitation
matches the expected verse sufficiently.
